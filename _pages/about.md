## Once in How Many Years? Extreme Value Analysis of Rainfall in Hong Kong [[code]](https://github.com/linus-lls/Capstone)
_Tang S.C., Lee L.S._  
Analysis pipeline for modelling extreme rainfall in Hong Kong using GEV, GPD, and max-stable models. I contributed mainly in block maxima approaches, Generalized Extreme Value Distribution, and max-stable processes.

## From Image to Cantonese Song: A Multimodal Pipeline for Lyric and Music Generation [[code]](https://github.com/linus-lls/Image2CantonSong)
_Tang S.C., Lee L.S., Ni B., Cheng Y.C., Sze H.K._  
Image2CantonSong is an end-to-end multimodal generation project that converts an input image into Cantonese lyrics and then generates a song through a lyrics-to-music pipeline. The system is designed as a research prototype and demo platform for exploring image understanding, Cantonese lyric generation, retrieval-augmented generation, music prompt engineering, and automatic evaluation. I contributed mainly in emotion prompting and image-lyrics correspondence evaluation.
